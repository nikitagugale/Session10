# docs/

This folder is yours. The milestones ask you to write their deliverables here:

| Milestone | File | What goes in it |
|---|---|---|
| 1 and 2 | `findings.json` | The facts you establish about the old credential, and what each tool really needs. The shape is in `LAB-GUIDE.md`. |
| 3 | `token-schema.md` | Your design for the scoped agent token. |

`LAB-LOG.md` (one level up) is your evidence log: what you tried, what you learned, which hints you used.
